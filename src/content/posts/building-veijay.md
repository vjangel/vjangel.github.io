旧版 VeiJay 由 Hexo 生成，发布仓库里存放的是 HTML、样式和脚本。新版迁移到 Astro 7，仓库开始跟踪页面组件、Markdown 和构建配置。首页将作品与技术笔记放在一起，分别提供列表和详情页。新增内容时，标题、摘要和日期跟着正文一起维护，首页和列表在构建时读取这些字段。

## 中英文内容

中文沿用根路径，英文页面放在 `/en/` 下。作品和笔记的两种语言各自使用 Markdown 文件，同名文件对应同一个条目。详情页切换语言时，读者会留在同一篇文章或同一件作品。缺少翻译时，页面会显示已有正文，并标明实际使用的语言。首页和页脚的社交链接共用一份配置，目前显示 GitHub，地址留空的平台会自动隐藏。

## 首页的流光背景

首页把半透明的内容面板放在 Canvas 背景前。移动鼠标会带出光带和拖尾，点击页面空白处会激起光波。柔光贴图在初始化时生成，后续绘制直接复用。画布位于页面内容下方，导航和作品链接可以照常操作。首页提供动效开关，首次打开时会参考系统的减少动态效果设置。切换到后台标签页会暂停绘制。作品详情和笔记页使用静态背景。

## 构建与发布

在新环境中可以用 Node.js 24 和 `npm ci` 按锁文件安装依赖，再运行 `npm run build` 生成静态页面。生成的文件放在 `dist/`，用 `npm run preview` 可以在本地检查这份构建结果。旧版发布文件仍可从 Git 历史中查到。

GitHub Actions 工作流已配置为在面向 `main` 的拉取请求中检查构建，在 `main` 更新时上传 `dist/` 并部署到 GitHub Pages。写这篇记录时，新版已在本地构建和预览，工作流还没有在 GitHub 上运行。首次发布需要将 Pages 的发布源切换为 GitHub Actions。
