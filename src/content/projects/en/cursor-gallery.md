Explore Windows cursor themes and compare designs for Normal Select, Text Select, Busy, and other pointer roles.

## Try it in your browser

Switch themes with thumbnails, arrow keys, or a swipe. Pause the animation or enable the live cursor to try a theme at your pointer position. The collection supports search, categories, and favorites; theme details include every role and its hotspot information.

The gallery has its own appearance and language controls. Use the back arrow in the header to return to VeiJay.

## Installation packages

Browser previews run within the gallery. Where a theme has a package available, its detail page links to the ZIP. Extract the package and follow the included Windows installation instructions for the ANI and CUR cursor files.
