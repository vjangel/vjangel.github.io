03 / 带回桌面

从展馆到你的桌面

下载主题 ZIP 并完整解压。打开解压后的文件夹，让 Animated 和 Static 子文件夹与安装文件留在同一目录。

Windows 7 / 10 / 11
A

用脚本安装并应用

在解压后的文件夹里双击 Install.cmd。它会为当前 Windows 用户注册动态和静态两种方案，并立即应用动态方案。

B

通过 INF 安装

右键单击 Install.inf。Windows 7 或 10 直接选择「安装」。Windows 11 如需展开旧版菜单，先选「显示更多选项」，再选「安装」。这会注册两种方案，安装后按下方步骤选择并应用。

↶

卸载主题

要卸载哪个版本，就在该版本解压后的文件夹里运行 Uninstall.cmd。

在 Windows 7、10、11 应用或切换方案

按 Win + R，输入 main.cpl 后回车。在「鼠标属性」中打开「指针」选项卡，在「方案」下拉框中选择对应的主题和版本。带 (Animated) 的是动态方案，带 (Static) 的是静态方案。选好后点「应用」或「确定」。

每个 ZIP 含 17 种角色。Windows 7 的「指针」选项卡只列出 15 个经典角色。支持扩展角色的 Windows 10 和 11 版本还会显示「位置选择」(Location Select) 和「人员选择」(Person Select)。
